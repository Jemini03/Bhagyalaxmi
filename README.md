# Bhagyalaxmi RMC

Bhagyalaxmi RMC is a web-based platform designed to support ready-mix concrete supply and aggregate transportation services.
The system aims to simplify customer enquiries, product selection, order placement, and order management through a centralized web interface.

## Main Modules

### 1. Public Website
- Company information and services
- Concrete and aggregate product information
- Concrete volume calculator, if implemented

### 2. Customer Module
- Browse available products
- Submit orders
- Enter delivery and contact information

### 3. Administration Module
- View customer orders
- Manage product information
- Track order status, if implemented

## Technology Stack

- Frontend: React and Vite
- Backend: Node.js and Express
- Database: MySQL
- API communication: HTTP and JSON

## Prerequisites

- Node.js and npm
- MySQL Server
- A code editor such as Visual Studio Code

## Installation

### 1. Clone the repository


git clone https://github.com/Jemini.03/Bhagyalaxmi.git
cd bhagyalaxmi-rmc


### 2. Install frontend dependencies


cd frontend
npm install


Start the frontend using:


npm run dev


### 3. Install backend dependencies

Open another terminal and navigate to the backend folder:


cd backend
npm install


Configure the backend environment variables according to your project's configuration before starting the server.

### 4. Database Setup

Create the required MySQL database and tables.

Use the SQL schema and setup instructions provided with the project. Configure the database connection using environment variables.
